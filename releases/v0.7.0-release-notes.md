# Yume v0.7.0 Release Notes

## Fixes

- **Thinking blocks**: Fixed multiple issues where thinking block content was not updating correctly in the UI, including truncated messages overwriting content
- **Windows thinking proxy**: Improved socket handling with keepalive, timeout settings, and better SSL options
- **Windows memory MCP**: Fixed MCP server path resolution on Windows
- **Socket errors**: Filtered noisy socket error logs from both frontend and Rust backend

## Improvements

- **Performance**: Removed 90d analytics, now uses Claude's default 30d analytics to prevent CLI slowdown
