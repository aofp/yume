# Yume v0.7.1 Release Notes

## Summary

Major fixes for thinking blocks - multiple blocks per session, content updates, and truncation issues.

## What's Fixed

- **Multiple thinking blocks**: Now properly supports multiple thinking blocks per session
- **Content updates**: Fixed thinking block content not updating in UI
- **Truncation fix**: Prevent final assistant message from truncating thinking content
- **First delta**: Allow first thinking_delta to create new message
- **Content overwrite**: Fixed thinking content being overwritten by truncated messages

## Technical Details

- Thinking router logging improvements
- Debug output for thinking block handling
- Fixes across multiple components for thinking block state management

## Upgrade Notes

Standard update - download and install over existing version.
