## 2. Show HN Post

**Title:** `Show HN: Yume – Native desktop GUI for Claude Code with thinking streaming`

**Body:**
```
Hey HN,

I built Yume because using Claude Code in the terminal was driving me crazy - the flickering, losing context, no visibility into token usage, accidentally closing sessions.

Yume is a native desktop app (Tauri 2.0 / Rust + React) that wraps Claude Code with 20+ features you can't get anywhere else:

- Thinking streaming - watch Claude's extended thinking in real-time (not even the CLI does this)
- Auto-compaction - dynamic context management so you never hit the wall unexpectedly
- 4 built-in agents - architect, explorer, implementer, guardian with orchestration flow
- Background agents - queue up to 4 concurrent agents with automatic git branch isolation
- Plugin system - commands, agents, hooks, skills, MCP all as markdown files
- 5h + 7-day limit tracking - visual bars for Anthropic's rate limits
- Crash recovery - auto-save every 5 minutes with 24hr restoration
- 18 themes (12 dark OLED + 6 light), 32+ keyboard shortcuts, rollback/history panel

It uses ~145MB RAM idle (vs 1GB+ for Electron-based alternatives). All features are free. Pro license ($29) just adds more tabs.

Built with: Tauri 2.0, Rust, React 19, TypeScript, Vite 7

GitHub: https://github.com/aofp/yume
Download: https://github.com/aofp/yume/releases

Happy to answer any questions about the architecture or Tauri 2.0 development experience.
```

**Posting tips:**
- Post Tuesday-Thursday, ~11am ET
- Don't ask for upvotes (HN bans this)
- Reply to every comment quickly in the first 2 hours
- Be genuine and technical - HN loves implementation details
